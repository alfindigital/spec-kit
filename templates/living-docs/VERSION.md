## Aturan Bump (ringkas)

- **MAJOR** — breaking API/schema, auth change, framework major upgrade, rilis stabil pertama
- **MINOR** — fitur baru backward-compatible, deprecation, integrasi baru
- **PATCH** — bugfix, security fix, perf, deps patch
- **Pra-1.0.0:** `0.Y.0` = fitur/breaking; `0.y.Z` = fix. Tidak ada jaminan stabilitas.
