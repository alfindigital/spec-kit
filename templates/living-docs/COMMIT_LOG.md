# COMMIT_LOG

> Indeks kronologis commit bermakna. **Update setiap push.**
> Anti-monster: file ini hanya indeks — detail diff/keputusan per hari di
> `commit-log/YYYY-MM-DD.md`.

## Indeks

| Tanggal | File detail | Highlight |
| :--- | :--- | :--- |
| [YYYY-MM-DD] | [commit-log/YYYY-MM-DD.md] | [1 kalimat] |

---

## Format `commit-log/YYYY-MM-DD.md`

```markdown
# Commit Log — YYYY-MM-DD

| Commit | Type | Ringkasan | File utama |
| :--- | :--- | :--- | :--- |
| [hash] | [feat/fix/refactor/chore] | — | — |

## Keputusan hari ini
- [keputusan teknis yang diambil + kenapa]
```
